# Job Preparation – 6sense HQ Limited

## Interview Focus Areas

### React Interview Questions

| Topic | Key Points |
|-------|------------|
| Virtual DOM | Lightweight representation, diffing algorithm, batched updates |
| Reconciliation | Keys for list identity, fiber architecture |
| useEffect cleanup | Return function for subscriptions, timers, abort controllers |
| Keys in lists | Stable identity, avoid index for dynamic lists |
| Controlled components | React state is source of truth |
| Event handling | Synthetic events, preventDefault |
| Performance | memo, useMemo, useCallback, lazy, code splitting |

### Next.js Questions

| Topic | Key Points |
|-------|------------|
| SSR vs SSG vs CSR | When each runs, use cases |
| getServerSideProps vs getStaticProps | Request vs build time |
| API routes | When to use, limitations |
| Image optimization | next/image benefits |
| App Router | Server vs Client Components, `'use client'` |

### JavaScript Questions

| Topic | Key Points |
|-------|------------|
| Closures | Function + lexical scope |
| Event loop | Call stack, task queue, microtasks |
| Prototypal inheritance | __proto__, prototype chain |
| this | Binding rules, arrow functions |
| Promises vs async/await | Same thing, different syntax |

## How to Use This for Q&A Practice

- Pick one row from each table (React, Next.js, JavaScript) and:
  - Explain the concept in **your own words**.
  - Provide a **short code example**.
  - Describe **where** you used it in your projects.
- For each listed project (e-commerce, dashboard, blog), prepare:
  - Tech stack
  - Main challenges
  - Key decisions (state mgmt, rendering strategy, performance choices)
